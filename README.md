# taehyeong1001.github.io

Personal research website of Taehyeong Kim (Mathematical Sciences, UNIST), built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) starter.

- Content: `_pages/`, `_projects/`, `_news/`, `_data/cv.yml`, `_data/socials.yml`
- Local preview: `bin/serve-local` → http://localhost:4000
- Deploy: pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site to the `gh-pages` branch.
